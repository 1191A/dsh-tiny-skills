# 把材料变成讲义

**交付物是一份 md 文件，不是一场对话。** 用户要的是能自己看、能反复看、能存下来的东西；聊天窗口里的讲解刷过去就没了。

材料本身不难找，难的是**材料是按"作者已经懂了"的顺序写的**：提纲式 PPT 只有结论，教辅解析从"作辅助线"开始，教材跳步时默认你能自己补。这个技能做的事，是把那种顺序重排成"一个还没懂的人能跟上的顺序"，并且把它写成文件。

## 交付什么

一份讲义，加上它真正引用到的那几张图，放在：

```
/sdcard/Download/DSH-Go/讲义-<材料名>/
├── <节名>.md
└── images/s011.png …
```

讲义的结构固定：

```markdown
# §10-3 电场强度

> 依据《第10章静电学》第 10–14 页整理。公式按原页面转写。

## 这一节要解决什么
（三五句话，说明这节的靶子）

## 1. 小节标题
（连贯的正文，不是要点罗列）

![图注](images/s011.png)

## 小结
1. … 2. … 3. …

## 自测三问
1. …
```

## 流程

### 第 0 步：材料体检

二进制文件先跑转换：

```bash
python3 ~/.dsh/skills/explain-material/scripts/ingest.py <文件>
```

得到 `source.md`（带位置标记）和 `images/`。`.ppt` 会逐页渲染成 `images/sNNN.png`，**公式在图里，必须看那张图**，不要依残缺文字猜式子。

然后做三件事：

1. **声明读到了什么**：多少页、哪些是图、哪几页读不出。读不出来的当场说，绝不猜。
2. **四判据体检**：材料病在哪（见 `references/material-check.md`）。
3. **拆节**：一份材料通常不止一节。一次只做一节——用户指定了就做指定的，没指定就先给目录让用户挑。

### 第 1 步：读材料

- 文字读 `source.md`。
- **凡是正文里出现公式、受力图、电路图、几何图的地方，都要打开对应的 `images/sNNN.png` 看**。只读文字写出来的讲义，公式一定是错的。
- 材料跳步的地方，自己先想通再写。

### 第 2 步：写讲义

规则见下节。样例见 `references/example-notes.md`。

### 第 3 步：打包

```bash
python3 ~/.dsh/skills/explain-material/scripts/pack.py <讲义.md> <抽图目录> <交付目录>
```

它只复制讲义里真正引用到的图。整章直接拷 `images/` 会有上百张、几十兆，没必要。

### 第 4 步：回复用户

聊天里只给三样，不超过六行：

1. 这份材料读到了什么、哪部分读不到（一行）
2. 讲义路径 + 讲了几节
3. 一句「哪一节想再拆细一点，说一声」

不要把讲义内容再在聊天里复述一遍。

## 写作规则

1. **连贯叙述，不按页切分。** 材料是一页一个要点，讲义要按"问题 → 办法 → 推广 → 边界"的线走。多页合成一节是常态。
2. **公式必须看页面转写**，并且放进代码块（三个反引号包围），避免阅读器把下标、希腊字母吃掉。
3. **图就近插**，紧跟在讲它的那段文字下面，图注写人话（"点电荷的场：只依赖 r，所以是球对称的"）。
4. **补推理，不复述。** 材料说"选适当的高斯面"，讲义要写清"为什么只有这种面能把 E 提出积分号"。这一条是整份讲义的价值所在。
5. **明确读不到。** 某页是扫描件、公式糊了、图被裁了，就在正文里写"这一页的材料读不到"。
6. **不超纲。** 要用材料外的方法，标一句"这条超纲，可跳过"，并给不超纲的替代路线。
7. **篇幅**：一节 800–1500 字。超过就要拆节，不要写成长篇。
8. **自测题的答案指回小节**，不要另附答案。

## 陪讲模式（用户明确要求时才用）

用户说「讲给我听」「一块一块讲」「陪我推一遍」时，切换成对话式：每块五段——一句话、独白（最多三句：卡在哪、被什么救出来）、主线（≤6 步）、停一下（一个答案唯一的问题）、边界。一次只发一块。形状见 `references/example-block.md`。

默认不要进入这个模式：用户要的是文件。

## 铁律

1. **读不出的不许猜。** 图、公式、手写、糊掉的扫描件，一律说读不到。
2. **公式必须来自页面。** 文字层里的公式是残的，按残文猜出来的式子会把整份讲义污染，而且学生不会发现。
3. **不擅自超纲。**
4. **不改题目。**
5. **不向学生报坐标。** 不要写"第 141 行"；要指认就说原话（"材料里那句'由内向外的方向为正'"）。讲义里引用页码只用于"依据第 10–14 页整理"这种来源说明。
6. **聊天里不复述讲义。**

## 和 no-hint-recall 的分工

- 本技能 = **输入**：把材料变成一份看得懂的讲义。
- `no-hint-recall` = **加工**：用户自己推的时候陪练。
- 讲义末尾可以提一句"要不要合上讲义自己推一遍"，但不要强行切换。
