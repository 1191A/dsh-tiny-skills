# 输入转换：把文件变成能读的东西

拿到的材料经常是二进制文件。不要直接让模型"看"一个 ppt——先跑 `scripts/ingest.py`，它会输出一份带位置的 md 和一个图片目录。

```bash
python3 ~/.dsh/skills/explain-material/scripts/ingest.py <文件> [-o 输出目录] [--asr]
```

产出：

```
<文件>_ingest/source.md      # 正文，带 [s12] / [p3] / [00:03:20] 这样的位置标记
<文件>_ingest/images/        # 抽出的图（公式、版面、视频帧）
```

**先读 `source.md` 顶部的「提取报告」，再决定讲什么。** 报告里写了几段文字、几张图、哪些没读到——这些就是讲的时候必须明说的部分。

## 各格式的能力与坑

| 格式 | 拿到什么 | 拿不到什么 |
|---|---|---|
| `.ppt`（97-2003） | **逐页渲染成 PNG** + 每页文字（POI/Java） | 少数特效动画、嵌入视频 |
| `.pptx` | 每页文字、`ppt/media` 里的图 | 不渲染版面（要渲染先用 Office 另存为 ppt） |
| `.pdf`（有文字层） | 分页文字，保留版式 | 图片里的公式要另外看 |
| `.pdf`（扫描件） | 每页转成 PNG | 没有文字，全靠视觉读 |
| `.docx` | 正文、内嵌图 | 批注、修订 |
| `.xlsx` | 单元格（需 openpyxl） | 图表 |
| 视频 | 按时间抽帧（最多 24 帧） | 讲解词（要加 `--asr`） |
| 音频 | `--asr` 后出转写 | — |
| 图片 | 原样放进 images/ | 需要视觉模型读 |

## 公式：已经解决了，靠本机渲染

物理、数学课件的公式几乎都是图片。只抽文字会得到这种断句：

> `定义：某场点的电场强度为 〔空〕`

现在 `.ppt` 会走 **Apache POI 逐页渲染**（`scripts/poi/`，Java 实现），输出 `images/s001.png …`，公式、图、版式全在画面里，视觉模型直接读。123 页的《静电学》大约 32 秒。

依赖：`java`（apt install default-jdk-headless）+ 中文字体（fonts-noto-cjk）。缺哪个会在报告的 ⚠️ 里说，并自动退回纯文字提取。

**踩过的坑，别再走：**
- LibreOffice 在这个容器里起不来（`/proc not mounted`，转换直接退出码 81），别装别试。
- `.pptx` 目前不渲染版面；要渲染，先在 Office 里另存为 `.ppt`。
- 渲染质量取决于原文件的字体；缺字体会出现方框，装 `fonts-noto-cjk` 即可。

**什么时候不用图**：只想快速看目录或提纲时，读 `source.md` 的每页文字就够，不必逐张读图。图是给"这一步看不懂"的地方用的。

## 语音转写

- DSH 内置的视频工具（`video_probe` / `video_storyboard`）需要 ffmpeg，已装；它们的 ASR 需要 API key。
- 没有 key 时用 `--asr`，走本地 faster-whisper（已装）。注意它有 PyAV 兼容问题，脚本里已经绕开（先 ffmpeg 抽 wav，再用数组喂模型）。
- 中文术语容易错，转写稿要按上下文校正，别直接当原文引用。

## 用之前先看一眼报告

启动任何讲解之前，先用一句话跟用户对齐：

> 这份材料 123 页，我逐页渲染成图了，文字也拿到了；第 40 页那个式子我看了图，是……

这句话本身就是技能的价值之一——**学生最怕的不是讲错，是讲的时候假装都看到了**。
