# §10-3 电场 电场强度

> 依据《第10章静电学》第 10–14 页整理。原文是提纲，本文把中间省略的推理补上了，公式按原页面转写。

---

## 这一节要解决什么

上一节说"场是物质，有能量和动量"，但这话没法用来算题。真正要回答的是：**给定空间里的一点，这个点的电场到底有多强、朝哪边？**

电场看不见，不能直接量。所以这一节的全部办法就一句话：**放一个探针进去测，然后从测到的东西里，把探针自己留下的痕迹除掉。**

---

## 1. 探针：试验电荷 q₀

材料给的定义是：试验电荷 q₀ —— **电量、几何尺度很小**。

为什么要小，材料没说，但这是整节的入口：

- **电量要小**：探针带电，就会反过来推源电荷。源一挪，你测的已经不是原来那个场了。
- **尺度要小**：场是逐点不同的。探针太大，测到的是它占的那一小块区域里的平均效果，不是"某一点"的场。

所以严格说，E 是 q₀ → 0 时的极限。材料里那句"q₀ 很小"不是客套，是定义成立的前提。

---

## 2. 定义：E = F / q₀

![电场强度的定义](images/s011.png)

在 P 点放一个 q₀，测到它受的力 F。定义：

```
E = F / q₀
```

材料的三条说明，其实回答了三个不同的问题：

**(1) 方向怎么定？**
E 的方向 = 单位正电荷受力的方向。所以 E 是**由源决定的**，不是由探针决定的。

**(2) 凭什么说 E 与 q₀ 无关？**
这是最容易卡住的一句。分母上明明挂着 q₀。

理由在库仑定律里：**F 正比于 q₀**。q₀ 加倍，F 也加倍，比值不动。所以 E 只依赖源电荷和场点的位置——它描述的是场，不是探针。

**(3) 单位**：N/C。力除以电荷，量纲就这么来的。

---

## 3. 点电荷的场

把 q₀ 代进库仑定律，再除以 q₀，q₀ 就消掉了：

```
E = (1 / 4πε₀) · (q / r²) · r̂
```

![点电荷的场](images/s013.png)

两件事值得注意：

- **q₀ 真的消掉了**——这就是上面第 (2) 条的具体验证。
- **方向跟着 q 的符号走**：q > 0，沿径向向外；q < 0，沿径向向内。r̂ 是从源指向场点的单位矢量。

材料说"点电荷的电场具有球对称性"，这句话不需要证明，它是从公式直接读出来的：式子里只有 r，没有方向角。

---

## 4. 叠加原理

一个电荷的场会算了，多个电荷怎么办？

**矢量和。** 每个电荷单独存在时在该点产生的场强 Eᵢ，加起来就是总场强：

```
E = E₁ + E₂ + … + Eₙ
```

关键在于：叠加是对**矢量**做的。方向不同的场不能直接加数值，得先分解到坐标轴上。

---

## 5. 从"几个电荷"到"一个带电体"

带电体上电荷是连续分布的，没法一个个数。做法是把带电体切成无数个电荷元 dq：

```
dE = (1 / 4πε₀) · (dq / r²) · r̂
E  = ∫ dE
```

材料把这一步标成了本节的学习重点，因为它把前面所有东西串起来了：**dq 当点电荷处理（用第 3 节），整体用积分求和（用第 4 节的叠加）**。积分是矢量积分，通常要先把 dE 分解成两个分量再分别积。

---

## 小结

1. E 是"力除以探针"，除完剩下的是场自己的性质。
2. 探针必须小，否则测的就不是那个点的场。
3. 点电荷的场正比于 q、反比于 r²，方向随符号变。
4. 多个源 → 矢量叠加；连续分布 → 切成 dq 再积分。
