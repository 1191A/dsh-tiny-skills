# 一个完整的块长什么样

下面是一份真实材料（大学物理《静电学》第 10-3 节，PPT 提纲，公式为图片）处理后的第一块。用来校准形状和长度，不要照抄内容。

材料原文只有这些字：`2.电场强度 / 定义：某场点的电场强度为 / 试验电荷qo-----电量、几何尺度很小 / (1)电场中某场点上的电场强度矢量等于置于该点的单位正电荷所受的电场力 / (2)与试验电荷qo无关 / （3）单位是N/C`。

---

**§10-3 电场强度 · 本节地图**

这一节解决一个问题：怎么描述一个看不见的场。拆四块：

1. 为什么要有"场"这个概念，E 为什么这样定义
2. 点电荷的场 + 叠加原理
3. 连续带电体：拆成 dq，再积分
4. 四个例题（偶极子、带电直线、圆环、圆盘）——同一套动作做四遍

材料里写了"学习重点是求连续带电体的电场"，所以 3、4 是主战场，前两块是地基。

---

**第 1 块 · 为什么是 F/q₀**

**一句话**：电场强度不是力，是"力除以电荷"；除完剩下的那部分，才是场自己的性质。

**独白**

> 读到"试验电荷要小"，第一反应是：测个力而已，为什么要小——大了会把源电荷推走，测到的已经不是原来那个场。
> 第二个卡点：E = F/q₀ 不还是依赖 q₀？——库仑定律里 F ∝ q₀，换探针力变、比值不变。

**主线**

1. 电荷不接触也相互作用 → 中间有东西 → 引入场
2. 场是物质，不只是数学工具
3. 描述"某点的场"，得拿探针测
4. 探针要小：电荷小不扰动源，尺度小才是"点"
5. F 随探针变 → 除以 q₀；因为 F ∝ q₀，比值只依赖源和位置

**停一下**：探针换成 2q₀，同一点测到的 F 和 E 分别怎么变？

**边界**：只对"源静止、电量不变"成立。探针大到能改变源分布，测出来的数没有意义——不是算错，是定义不成立。

---

## 从这个例子能看出的几条

1. **独白只有两句，但它干了最重的活。** 材料里"试验电荷很小"这五个字，是作者顺手写的；学生真正卡住的地方在这里。
2. **主线五步，没有一步是计算。** 计算可以留给学生，判断不能。
3. **"停一下"的答案唯一。** F 变大、E 不变。答错就说明没懂，比"理解了吗"有效一万倍。
4. **边界一句话就够。** 但缺了它，学生会把这个定义用到非静电场上去。
5. **全文没有出现材料里没有的新方法。** 只有库仑定律和"物质"这个概念，都是材料已有的。
